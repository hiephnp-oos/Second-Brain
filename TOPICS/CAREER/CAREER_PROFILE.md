# Career Profile

## Purpose

Canonical durable career-fit baseline shared by the Career workstreams. This file should contain stable context, not individual job records.

## Geography

- Primary focus: Da Nang / Quang Nam / Central Vietnam.
- Relocation outside the preferred geography is a material decision factor and must be verified rather than assumed acceptable.

## Target Role Families

- Manufacturing Quality
- Supplier Quality / SQE
- NPI / New Product Introduction
- Industrialization / Process Engineering
- Validation / Product or Manufacturing Quality Engineering
- Related engineering / quality roles where the user's existing manufacturing and R&D background transfers credibly

## Core Capability Context

- Manufacturing R&D engineering background.
- Product development and industrialization exposure.
- Quality-related methods and systems including PPAP, FMEA, IATF 16949, ISO 9001, Stage Gate, GD&T, and related manufacturing quality practices.
- Engineering tools and practical problem solving in a manufacturing environment.
- AI-assisted analysis, research, automation, and workflow design are additional capabilities that may create value beyond conventional engineering roles.

## Compensation Direction

- A target around USD 1,000+ is a useful screening signal when reliable compensation information is available.
- Missing salary information is not itself a rejection reason; compensation should be treated as confirmed, estimated, or unknown.

## Language / Role Constraints

- Mandatory Chinese is a hard blocker when the role requires it and the user does not meet the requirement.
- Chinese preferred is a risk / fit factor, not an automatic rejection.
- Missing experience must not be fabricated or presented as existing competence.

## Decision Categories

Use these categories consistently when evaluating opportunities:

- `APPLY / PRIORITIZE` — evidence supports a credible fit and no known hard blocker is present.
- `CONSIDER / VERIFY` — potentially relevant, but a material uncertainty needs verification.
- `RISK` — relevant opportunity with one or more meaningful gaps or constraints that should be explicitly surfaced.
- `REJECT` — a documented hard blocker or an explicit user decision excludes it.

The category is a decision aid, not a permanent truth. New evidence can change the state.

## Durable Exclusions / Explicit Decisions

Keep only durable decisions here. Individual application outcomes should remain in the user's external tracking system unless they change a reusable rule.

Examples of durable constraints include:

- Do not prioritize roles requiring relocation far from the target Central Vietnam geography unless the user explicitly changes this preference.
- Do not repeat opportunities the user has explicitly rejected unless new evidence materially changes the reason for rejection.
- Do not treat absence of one preferred skill as equivalent to absence of all transferable capability.
- Before rejecting a borderline role, check for credible transferable experience and supporting evidence.

## Maintenance Rule

Update this file only when new information materially changes how future career searches should be performed across multiple workstreams. Job-specific facts belong to the external job-tracking system unless they become a durable rule.
