# Company Values

## Purpose

Define company values that guide behavior, decision-making, and hiring in a minimalist organization.

---

## When to Apply

- Preparing to hire first employees
- Formalizing company culture
- Aligning team behavior and expectations
- Scaling beyond founder-only operation

---

## Core Principle

Define culture before scaling team.

Values should:
- guide real behavior (not slogans)
- influence decisions in ambiguous situations
- attract aligned people and filter out misaligned ones

---

## Role of Values

Values serve to:

- Define expected behavior in daily work
- Guide decisions in edge cases
- Align team without excessive rules or documentation
- Enable consistent culture as team grows

---

## Value Design Framework

### 1. Non-Obvious Beliefs

Identify:

- What the company believes that others do not
- Perspectives that may be unconventional or specific

---

### 2. Behavior Definition

Clarify:

- How people act without supervision
- Expected standards in execution and communication

---

### 3. Boundary Conditions

Define:

- What behavior is unacceptable (even if performance is high)
- What behavior is rewarded (even without direct business impact)

---

### 4. Story-Based Expression

Avoid generic phrases.

Instead:
- Describe values through concrete examples or scenarios
- Show how values are applied in practice

---

## Operationalization

Integrate values into:

- Hiring criteria
- Performance feedback
- Internal communication
- Decision-making processes

Values must be:
- visible
- referenced
- enforced consistently

---

## Remote Work Considerations

If operating remotely:

- Prioritize asynchronous communication
- Document decisions and processes
- Emphasize ownership and accountability
- Measure output, not activity

---

## Constraints

- No generic values (e.g., “integrity”, “excellence” without context)
- No values disconnected from actual behavior
- No over-documentation instead of cultural clarity
- No hiring before defining expectations

---

## Output

Define clearly:

1. 3–5 company values (with explanation)
2. Example behaviors for each value
3. How each value influences hiring decisions
4. How each value appears in daily operations
5. Anti-patterns (what violates each value)
