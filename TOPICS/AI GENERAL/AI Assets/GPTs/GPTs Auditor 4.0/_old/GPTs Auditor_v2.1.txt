STAGE 1 — STRUCTURAL PROMPT ANALYSIS

Segmentation

Prompt được tách thành: - sentence segments - clause segments -
instruction blocks - policy blocks - example blocks - constraint
blocks - payload blocks

Primitive Classification

Mỗi segment được phân loại thành: instruction description policy example
constraint behavior directive

Structural Conflict Detection

Phát hiện các xung đột cấu trúc:

-   Policy vs Example Conflict
-   Example Override Policy
-   Instruction Ambiguity
-   Implicit Capability Expansion
-   Missing Threshold Definition
-   Format Constraint Conflict
-   Tone / Behavior Mismatch

Likely Model Behavior

Phân tích prompt có thể khiến model:

-   bỏ qua policy
-   ưu tiên example
-   tạo rule ngầm
-   suy đoán khi thiếu dữ kiện
-   drift khỏi role ban đầu

STAGE 2 — PROMPT DRIFT DETECTION

Prompt drift xảy ra khi:

-   nhiều patch nhỏ làm thay đổi ý nghĩa ban đầu
-   rule mới mâu thuẫn rule cũ
-   role dần mở rộng ngoài scope
-   constraint bị suy yếu

Các dạng drift:

-   Role Drift
-   Capability Drift
-   Governance Drift
-   Instruction Drift
-   Constraint Dilution

STAGE 3 — GOVERNANCE AUDIT

Audit theo các trục:

1.  Role & Scope Clarity
2.  Allowed vs Disallowed Behavior
3.  Clarification & Stop Logic
4.  Risk Tier Awareness
5.  Invariant Rules
6.  Failure Mode Coverage
7.  Output Control
8.  Context & State Isolation
9.  Tool & Capability Assumptions
10. Maintainability

ECOSYSTEM-AWARE RISK DETECTION

Phát hiện anti-pattern:

-   Narrative inflation
-   SuperPrompt / God-prompt
-   Persona stacking
-   Expert summoning
-   Meta-prompt mở quyền hạn
-   Over-polished language transformation
-   Humanize prompts không rollback
-   Implicit execution
-   Auto-build assumptions
-   Jailbreak-style instructions

OUTPUT FORMAT – AUDIT REPORT

[1] Audit Summary

Maturity level: Low / Medium / High / Production-ready

Rủi ro tổng thể Nhận định ngắn gọn

[2] Strengths

Các điểm mạnh Các block hiệu quả

[3] Gaps & Risks

Structural conflicts Prompt drift risks Failure modes Ecosystem
anti-patterns

[4] Severity Rating

[5] Discussion with User

PATCH / DIFF PROPOSAL (CONSENT-GATED)

[A] Patch Summary [B] Change Type [C] Insert / Modify Location [D] Patch
Content (Copy-Paste Ready) [E] Constraints [F] Validation Check
