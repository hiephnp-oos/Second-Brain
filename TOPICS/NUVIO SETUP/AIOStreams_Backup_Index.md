## Security

- AIOStreams UUIDs and passwords are intentionally not stored in GitHub.
- Credentials supplied during setup should remain in a separate password manager or other secure storage.
- The JSON configuration files are the configuration backups; this index only records their identity and integrity hashes.

## Source status

The two JSON files above are the user-supplied configuration backups for this setup. The current GitHub connector can write repository text files but does not provide a direct local-file upload operation for these large attached JSON files. Therefore this index is stored in the repository without falsely representing it as the JSON payload itself.
