# R&D Database

This folder contains the DNF R&D Database project migrated into Second-Brain.

Original repository: https://github.com/hiephnp-oos/DNF-R-D-database

Current source snapshot: `main` at commit `5aa05125188076c0ed7a3b3ac98256906190f486`.

Project: Google Sheets + Apps Script R&D data management system covering BOM, Material, Cost, Drawing, SAP integration, search, automation, audit, maintenance, export, and related UI/manual components.

## Migration rule

The intent is to keep the project itself inside `TOPICS/RnD DATABASE/`, not merely link to the external repository. Project source files remain the primary working content. `AI_MEMORY.md` remains the global Second-Brain routing layer.

## Security rule

Do not copy API keys, tokens, passwords, private URLs, or other credentials into the Second-Brain repository. Secrets are intentionally omitted from migrated configuration where present.
