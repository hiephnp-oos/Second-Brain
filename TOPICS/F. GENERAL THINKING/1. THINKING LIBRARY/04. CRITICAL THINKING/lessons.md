# Critical Thinking — Lessons

## CR-L-01
The ability to argue for a conclusion is not evidence that it is correct.

## CR-L-02
A useful belief includes conditions under which it would change.

## CR-L-03
Base rates and alternative explanations protect against attractive case narratives.

## CR-L-04
Confidence is not evidence quality.

## CR-L-05
Hindsight can make uncertain events look inevitable.

## CR-L-06
Fast intuition is context-dependent; feedback quality matters.

## CR-L-07
When equivalent framing changes a decision, investigate whether the preference is stable.

## CR-L-08
Actively searching for evidence that could make the current view wrong is a core discipline.
