# Critical Thinking — Mental Models

- CR-MM-01: ask “Is it true?” before “Can I defend it?”
- CR-MM-02: state what evidence would change the belief.
- CR-MM-03: use the outsider test.
- CR-MM-04: separate confidence from evidence.
- CR-MM-05: start with the base rate.
- CR-MM-06: inspect the anchor.
- CR-MM-07: test salience against frequency.
- CR-MM-08: reframe equivalent choices.
- CR-MM-09: check regression to the mean.
- CR-MM-10: slow down when intuition is unreliable.
