# Negotiation — Mental Models

- NEG-MM-01: improve the walk-away before arguing harder.
- NEG-MM-02: translate positions into interests.
- NEG-MM-03: create value before dividing value.
- NEG-MM-04: use objective standards.
- NEG-MM-05: separate people problems from substantive problems.
- NEG-MM-06: tactical empathy is understanding, not agreement.
- NEG-MM-07: “No” can reveal boundaries.
- NEG-MM-08: calibrated questions transfer problem-solving pressure.
- NEG-MM-09: agreement requires execution evidence.
- NEG-MM-10: search for hidden information.
