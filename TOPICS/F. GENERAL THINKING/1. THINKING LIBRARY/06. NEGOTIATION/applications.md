# Negotiation — Applications

- NEG-APP-01: supplier/contractor negotiation → map interests, BATNAs, criteria, timing and alternatives.
- NEG-APP-02: stakeholder conflict → separate relationship/emotion from substantive issues.
- NEG-APP-03: difficult counterpart → use empathy, labels, calibrated questions and controlled pacing.
- NEG-APP-04: concession → identify what is received in return.
- NEG-APP-05: final agreement → confirm owner, action, timing, dependency and failure handling.
