# Bayesian Thinking — Concepts

- Generative model: specify how observations could have been produced.
- Priors make assumptions explicit before current evidence.
- Likelihood + prior produce posterior beliefs.
- Posterior prediction tests useful consequences of a model.
- DAGs expose causal assumptions, confounding, mediation and collider structure.
- Partial pooling/regularization stabilizes estimates across related groups.
- Model checking asks whether the model reproduces important observed features.
- Base rates/reference classes constrain vivid case narratives.
- Calibration connects probability statements with long-run outcomes.
- Updating should be proportional to diagnostic evidence.
