# Bayesian Thinking — Concepts

Sources: Book 07 *Statistical Rethinking*; Book 08 *Superforecasting*.

## Generative reasoning
A generative model describes how observations could have been produced. It makes assumptions explicit and exposes testable consequences.

## Priors, likelihood and posterior
Priors represent information/assumptions before current evidence. Likelihood describes how probable evidence is under candidate states. Posterior belief combines both.

## Prediction and model checking
Posterior prediction tests useful consequences of a model. Model checking asks whether the model reproduces important observed features.

## Causal structure
DAGs make assumptions about confounding, mediation and collider structure visible. Causal reasoning depends on the structure assumed, not only on correlations.

## Partial pooling
Related groups can share information while retaining group-level differences. Partial pooling can stabilize estimates when some groups have limited data.

## Forecasting
Superforecasting adds reference classes, decomposition, base rates, incremental updating, calibration and scoring.

## Practical synthesis
Define target → establish base rate/prior → specify model → predict → observe evidence → update → check model/calibration.
