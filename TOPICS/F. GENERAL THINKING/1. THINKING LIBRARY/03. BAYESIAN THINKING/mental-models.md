# Bayesian Thinking — Mental Models

## BAY-MM-01 — Start with the generative story
Ask how the observation could have been produced.

## BAY-MM-02 — Make assumptions visible
Write down priors, causal assumptions and important exclusions.

## BAY-MM-03 — Evidence is not the model
A data point constrains a model; it does not automatically reveal the causal story.

## BAY-MM-04 — Predict before declaring success
Generate observable implications and test them.

## BAY-MM-05 — Outside view before inside view
Use base rates/reference classes before building a case-specific narrative.

## BAY-MM-06 — Update incrementally
Adjust belief in proportion to diagnostic evidence rather than waiting for certainty.

## BAY-MM-07 — Probability exposes uncertainty, not truth
A numerical probability can still be poorly calibrated or based on a bad model.

## BAY-MM-08 — Search for disconfirmation
Ask what observation would materially reduce confidence.

## BAY-MM-09 — Inspect causal role before conditioning
Conditioning on a variable can remove or create apparent associations.

## BAY-MM-10 — Score forecasts
Compare probabilistic predictions with outcomes to improve calibration.

## BAY-MM-11 — Separate model and parameter uncertainty
Uncertainty can concern values inside a model or the model structure itself.

## BAY-MM-12 — Repeated predictive failure is model evidence
Persistent miscalibration should trigger model revision, not only confidence adjustment.
