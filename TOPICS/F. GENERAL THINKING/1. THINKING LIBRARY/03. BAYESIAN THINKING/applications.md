# Bayesian Thinking — Applications

## BAY-APP-01 — Project forecast
Start with historical completion/base-rate information, then adjust for project-specific evidence. Record probability before outcome.

## BAY-APP-02 — Technical claim
Specify expected observations if the claim is true and alternative explanations that could produce the same observation.

## BAY-APP-03 — Quality diagnosis
Use causal structure to separate correlation from likely cause. Update confidence as tests discriminate mechanisms.

## BAY-APP-04 — Career decision
Use reference classes and explicit uncertainty rather than treating one attractive opportunity as representative.

## BAY-APP-05 — Technology assessment
Separate evidence about existence, performance and scalability; update each claim independently.

## BAY-APP-06 — Forecast review
Compare prior probability, updates and outcome. Classify error as base-rate, evidence-weighting, model or calibration error.
