# Source Traceability

This folder contains source-level traceability for the accepted books owned by this framework.

## Contract
- One traceability file per source book.
- PDF is the canonical source.
- Markdown is an extraction/retrieval aid and never overrides the PDF.
- Traceability records acceptance status, source identity, and validation notes.
- Full copyrighted source text is not stored in the public repository.
