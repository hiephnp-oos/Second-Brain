# Game Theory — Source Applications

Source: *Thinking Strategically* — Dixit & Nalebuff (GT-01)

This file records application patterns used by the authors. These are source-derived examples, not claims about the user's own experience.

## 1. Competitive pricing

The book uses competing magazines to show best-response reasoning and equilibrium.

Application pattern:
- map each player's response to the other's price;
- find where the best-response functions meet;
- treat that point as a candidate stable outcome;
- separately evaluate whether the stable outcome is desirable.

## 2. High-definition television competition

The book uses a U.S.–Japan R&D race to show how an unconditional move can alter a simultaneous game.

Application pattern:
- identify the opponent's likely response under the current rules;
- move first or commit to an action when doing so changes the opponent's incentives;
- recognize that a self-imposed constraint can create strategic advantage.

## 3. Nuclear deterrence

The book uses NATO/Soviet deterrence to show why a threat that is undesirable to carry out may fail without commitment.

Application pattern:
- model the opponent's decision first;
- ask what the opponent predicts you will do after their move;
- if your announced response is not credible at that point, the threat does not change their behavior;
- introduce a commitment mechanism if appropriate.

## 4. OPEC / prisoners' dilemma

The Iran–Iraq production example illustrates how individually rational defection can undermine a jointly better cooperative outcome.

Application pattern:
- identify each actor's dominant incentive;
- identify the cooperative outcome;
- identify how cheating is detected;
- identify what punishment sustains cooperation.

## 5. Repeated cooperation with imperfect observation

The book's tit-for-tat discussion shows how one misinterpretation can create an extended retaliation cycle.

Application pattern:
- distinguish actual defection from perceived defection;
- avoid treating one noisy observation as conclusive evidence;
- use short-, medium-, and long-term evidence;
- calibrate punishment and forgiveness to the probability of error.

## 6. Bargaining

The book analyzes alternating-offer bargaining.

Application pattern:
- model the sequence of offers and counteroffers;
- account for the shrinking value of delay;
- analyze the disagreement outcome;
- reason backward from the final credible choices.

## 7. Voting and agenda control

The voting chapter treats agenda setting as a strategic variable.

Application pattern:
- identify the order in which choices are presented;
- determine how earlier choices alter later options;
- do not assume the final result follows directly from aggregate preferences.

## 8. Incentive design

The book uses institutional and organizational examples to show that rules can create behavior that participants optimize locally but that produces an undesirable aggregate result.

Application pattern:
- model the actor's objective under the current rules;
- predict the behavior the rules reward;
- change the incentive or constraint rather than relying only on instructions.
