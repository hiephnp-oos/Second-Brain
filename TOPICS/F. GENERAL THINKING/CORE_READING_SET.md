# Core Reading Set

## Intake status

The current Core Reading Set contains 16 books supplied by the user. Statistical Rethinking is split into two Markdown extraction files because the source set contains two PDF parts.

Raw PDFs and full extracted book text are retained in the user's private BOOK intake. This public repository stores metadata and distilled knowledge, not full copyrighted books.

## Processing rule

Do not read the set as a flat list. Use the Thinking Map to route a book/framework to the reasoning problem it helps solve. Extract durable concepts first; applications and personal lessons are added only when actually useful.
