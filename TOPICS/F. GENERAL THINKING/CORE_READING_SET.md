# Core Reading Set

## Intake status

The current Core Reading Set contains 16 books supplied by the user. Statistical Rethinking is split into two Markdown extraction files because the source set contains two PDF parts.

The reading set is a current source selection. It does not define the permanent framework architecture.

Raw PDFs and full extracted book text are retained in the user's private BOOK intake. This public repository stores metadata, intake status, structural findings, and later distilled knowledge, not full copyrighted books.

## Processing rule

Do not read the set as a flat list. Use the Thinking Map to route a book/framework to the reasoning problem it helps solve.

The routing is not a claim that a book belongs exclusively to one theory. It is a practical primary/secondary classification for intake and later distillation.

Extract durable concepts first. Promote mental models, applications, lessons, and personal principles only when they demonstrate reusable value.

## Current reading architecture

The current set supports the initial six Thinking Library domains and the two cross-cutting synthesis lenses defined in \`ARCHITECTURE_PROPOSAL_V2.md\`.

A new book may be added or removed from the Core Reading Set without requiring a redesign of the framework architecture.
