# 03 — A Course in Game Theory

**Source:** Martin J. Osborne & Ariel Rubinstein, *A Course in Game Theory*  
**Review status:** Formal foundation

## Core thesis
Game theory provides a formal language for interactive decision problems. The same game frame can produce different behavior when preferences, information, timing, or beliefs change.

## Reusable knowledge
- A game must specify players, strategies/actions, information, and preferences/payoffs.
- Strategic-form reasoning emphasizes strategy profiles and best responses.
- Dominance can eliminate strategies, but weak dominance requires more care than strict dominance.
- Nash equilibrium is a mutual best-response condition, not necessarily a socially optimal outcome.
- Mixed strategies can be necessary when pure strategies do not yield an equilibrium or when unpredictability matters.
- Extensive-form games encode timing and information; backward induction is a key solution concept for appropriate finite perfect-information games.
- In incomplete-information games, beliefs about types matter in addition to material payoffs.
- Sequential equilibrium / related refinements address whether off-path beliefs and actions are credible.
- Repeated and dynamic interaction can support outcomes unavailable in a one-shot game.

## Operational translation
When a situation feels strategically confusing, formalize:
`players → strategy sets → information → preferences → timing → solution concept`

Then test whether the conclusion is robust to plausible changes in assumptions.

## Limitation
This is a formal textbook, not a lightweight decision guide. Its value for Second-Brain is the conceptual vocabulary and discipline, not memorizing every theorem.
