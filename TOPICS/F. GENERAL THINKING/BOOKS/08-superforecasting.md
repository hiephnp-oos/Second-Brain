# 08 — Superforecasting

**Source:** Philip E. Tetlock & Dan Gardner, *Superforecasting*  
**Review status:** Core forecasting source

## Core thesis
Forecasting improves when uncertainty is acknowledged, probabilities are explicit, predictions are decomposed into tractable components, base rates are used, and forecasts are updated as evidence changes.

## Reusable knowledge
- Start with the outside view and base rates before constructing a detailed story.
- Decompose broad questions into smaller estimable questions.
- Use explicit probabilities instead of vague confidence language.
- Update incrementally rather than making dramatic revisions from one new signal.
- Seek disconfirming evidence.
- Track forecasts against outcomes; calibration requires feedback and scoring.
- Good forecasting combines open-mindedness with disciplined skepticism.
- Teams can outperform individuals when aggregation preserves independent information and avoids social conformity.
- Forecasting is a process of continual revision, not a one-time prediction.

## Practical loop
`Reference class → initial probability → decomposition → evidence → update → record → score → learn`

## Limitation
Forecasting skill is domain-dependent. A well-calibrated forecaster still cannot predict inherently unpredictable events with high certainty.
