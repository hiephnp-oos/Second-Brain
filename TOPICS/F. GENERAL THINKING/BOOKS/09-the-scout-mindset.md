# 09 — The Scout Mindset

**Source:** Julia Galef, *The Scout Mindset*  
**Review status:** PARTIAL SOURCE — supplied PDF/MD is a Bookey-style summary, not the complete book

## Core thesis
Better reasoning requires treating beliefs as models of reality rather than identities to defend. The scout mindset prioritizes accurate understanding over winning, status, comfort, or group loyalty.

## Reusable knowledge
- Ask “Is it true?” rather than “Can I defend it?”
- Separate confidence from identity.
- Actively look for evidence that would prove your current belief wrong.
- Use the double-standard test: would I judge the same evidence differently if the sides were reversed?
- Use the outsider test: how would an uninvolved observer interpret the situation?
- Notice whether disagreement triggers defense, status protection, or curiosity.
- Reward useful criticism instead of treating disagreement as hostility.
- Intelligence does not immunize a person against motivated reasoning.

## Application
For an important belief:
1. State the belief and confidence.
2. Name what evidence would change it.
3. Search specifically for disconfirming evidence.
4. Ask how you would judge the same case if the roles were reversed.
5. Update visibly.
