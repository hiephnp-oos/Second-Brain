# Thinking Map

Routing map, not a second source of truth.

| Situation | Primary | Supporting |
|---|---|---|
| Multiple actors respond | Game Theory | Negotiation, Psychology |
| Complex interacting system | Systems Thinking | Strategic Thinking, Root Cause |
| Uncertainty / incomplete information | Bayesian Thinking | Decision Frameworks |
| Ambiguous / biased reasoning | Critical Thinking | Bayesian, Psychology |
| Human influence / behavior | Psychology | Game Theory, Critical Thinking |
| Negotiation | Negotiation | Game Theory, Psychology |
| Important decision | Decision Frameworks | Bayesian, Game Theory, Systems |
| Strategy / competitive position | Strategic Thinking | Game Theory, Systems |

## Physical taxonomy
1. Game Theory
2. Systems Thinking
3. Bayesian Thinking
4. Critical Thinking
5. Psychology
6. Negotiation
7. Decision Frameworks
8. Strategic Thinking

Use the narrowest useful lens first. Cross-link instead of duplicating knowledge.
