# Strategic Patterns

## Change the game before optimizing the move
When direct optimization is weak, inspect whether timing, information, incentives, commitments, or available options can be changed first.

Contributing libraries: Game Theory, Strategic Thinking.

## Diagnose structure before adding effort
If a problem persists despite more effort, inspect feedback loops, delays, rules, information flows, and incentives before increasing activity.

Contributing libraries: Systems Thinking, Strategic Thinking, Psychology.

## Make uncertainty explicit before commitment
Use base rates and evidence to establish uncertainty, then evaluate options against downside and reversibility.

Contributing libraries: Bayesian Thinking, Forecasting, Decision Frameworks.

## Separate persuasion from truth
A message can be persuasive because of social mechanisms without being correct. Evaluate the claim independently from the influence mechanism.

Contributing libraries: Psychology, Critical Thinking.

## Preserve future interaction value
In repeated relationships, today's response changes future incentives, reputation, and cooperation possibilities.

Contributing libraries: Game Theory, Cooperation, Negotiation.

## Focus creates leverage
A strategy becomes more coherent when diagnosis narrows the problem and actions reinforce one another.

Contributing libraries: Strategic Thinking, Systems Thinking.

## Boundary
These patterns are integrative summaries. The source mechanisms remain in their physical framework libraries.
