# Decision Patterns

## Pattern 01 — Decision under uncertainty
Problem → outside view/base rate → causal or generative model → explicit probabilities → alternatives → premortem → precommitment → action → outcome review.

Primary owners: Bayesian Thinking, Forecasting, Decision Frameworks, Critical Thinking.

## Pattern 02 — Strategic decision
Diagnosis → actors/incentives → likely responses → system feedback → guiding policy → coherent action → response monitoring.

Primary owners: Strategic Thinking, Game Theory, Systems Thinking.

## Pattern 03 — Negotiated decision
Interests → BATNA → counterpart incentives → information gaps → options → objective criteria → credible commitments → agreement → execution confirmation.

Primary owners: Negotiation, Game Theory, Psychology.

## Pattern 04 — Belief update after a surprising outcome
Observed outcome → separate result from decision quality → inspect assumptions → compare forecast with base rate → identify cognitive distortion → update model.

Primary owners: Decision Frameworks, Bayesian Thinking, Critical Thinking, Psychology.

## Guardrail
These are retrieval sequences, not mandatory checklists. Skip stages irrelevant to the problem structure.
