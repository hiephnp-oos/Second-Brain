# Meta-Models

## Model the structure before selecting the framework
Strategic response → Game Theory. Feedback and persistence → Systems Thinking. Uncertain evidence → Bayesian Thinking. Reasoning quality → Critical Thinking. Human influence → Psychology. Agreement → Negotiation. Decision quality → Decision Frameworks. Diagnosis and leverage → Strategic Thinking.

## Separate four questions
1. What is happening?
2. What might happen next?
3. What should we choose?
4. How should we change the situation?

Do not use a framework to answer a question it was not designed to answer.

## Keep model, evidence, and action separate
Evidence → model → inference → decision → action → observation → update.

A persuasive explanation is not automatically evidence. A good outcome is not proof that the decision process was good.

## Use cross-links instead of duplication
When two libraries discuss the same surface topic, identify the distinct mechanism each contributes. If no distinct mechanism exists, do not create another durable note.

## Escalate complexity only when needed
Start with one framework. Add a second only when the first leaves an identified blind spot. Add more only when the combined model changes the decision.

## Ownership
Meta-models govern how multiple libraries are selected or combined; they do not replace any library's underlying knowledge.
