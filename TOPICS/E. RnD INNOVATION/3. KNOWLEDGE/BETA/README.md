# BETA Knowledge Sheet

## Purpose and authority

BETA is the working Knowledge Sheet, with the same dataset layout and schema as the released baseline. It is non-authoritative and is not the team-published source of truth.

## Baseline

This BETA was initialized as a copy of `RELEASED/Release_23Sep2026/`. The original release remains unchanged and authoritative until a later release is explicitly approved and designated.

## Update policy

BETA is not continuously or automatically updated. Update it only when the user explicitly requests a batch and identifies the source scope, such as selected ADTD Claw records, Idea Review outputs, internet research, or a new supplier catalog. Schedule completion alone never triggers a BETA update.

Each batch must preserve provenance and evidence states; check duplicates, contradictions, IDs, relationships, and schema; and report the changes made and unresolved issues. BETA update and publication are separate decisions.

## Release

When the user considers BETA sufficiently mature, they may request a separate release review. Only an explicitly approved release creates a new versioned snapshot under `RELEASED/`. Never overwrite an existing release.
