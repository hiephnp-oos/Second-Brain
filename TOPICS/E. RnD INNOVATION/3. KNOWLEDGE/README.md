# Knowledge Lifecycle

R&D Innovation knowledge is separated by lifecycle state.

## Released

`RELEASED/3.1 KNOWLEDGE_SHEET/` contains the current authoritative, human-verified Knowledge Sheet.

## Candidate / Test

`CANDIDATE_TEST/` contains non-authoritative proposed, experimental, and unverified knowledge.

Research and workstream outputs remain owned by their invoking workstream and are not automatically copied into either lifecycle state.
