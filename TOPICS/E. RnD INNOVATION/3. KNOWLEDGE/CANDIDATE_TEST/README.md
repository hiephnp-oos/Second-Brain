# Knowledge Candidates / Test

## Purpose

Non-authoritative knowledge candidate and test space for proposed findings, relationships, experimental structures, and other knowledge awaiting verification.

## Lifecycle

`Candidate → Verify / Test → Human Review → Release or Hold / Reject`

Only human-verified knowledge promoted through `KNOWLEDGE_PROMOTION` may enter the Released Knowledge Sheet.

## Boundary

This folder is not source of truth. Preserve evidence state and uncertainty explicitly.
