## RS-10 — Market Pull Scout

### MP-01 — Handshower hose wants to twist, protrude, or occupy the user's body path
**Status:** EVIDENCED signal; proposed architecture is PROPOSED.

- WHO: users of handheld showers, especially systems where the hose hangs near the user's standing position or repeatedly rotates during use.
- CONTEXT: hose geometry, wall connection orientation, and repeated handshower movement can cause the hose to twist, protrude into the user's space, or interfere with controls/body movement.
- NEED / PAIN: keep the hose predictable and out of the user's way while retaining free handshower movement.
- BEST EXISTING SOLUTION: swivel hose connectors, flexible/kink-resistant hoses, and conventional wall docks.
- WHAT IT SOLVES: swivel connectors reduce torsional loading; flexible hoses improve handling; docks retain the handshower.
- REMAINING LIMITATION: these solutions do not necessarily control the hose's parked/neutral path. User reports still describe hoses protruding, moving sideways, or returning to an unwanted position.
- MEANINGFUL DELTA: control the hose's neutral parking path while preserving low-torque rotation during handshower movement.
- REQUIRED FUNCTION: decouple hose torsion from the wall connection and provide a passive, low-profile hose-routing/parking path that biases the hose away from the user's body and controls its return position.
- Evidence: user reports describing hose protrusion/return behavior; commercial swivel connector precedent from GROHE.
- External evidence: https://www.reddit.com/r/Plumbing/comments/1881fs7/shower_hose_sticks_out_shower_head_moves/ ; https://www.reddit.com/r/HomeImprovement/comments/18to6gl/my_shower_hose_keeps_returning_back_to_its_original_position/ ; https://www.lowes.com/pd/GROHE-Movario-59-in-Metal-Faucet-Spray-Hose/3186801
- Existing Knowledge: TR-017 Self-Centring Blind-Mate Fluid Couplings is a relevant transfer signal for passive misalignment compensation; it is not direct evidence of shower hose routing performance.

## RS-11 — Tech Push Scout

### TP-01 — Pressure-differential-triggered hydraulic backflush cleaning
**Status:** EVIDENCED technology; shower transfer is UNKNOWN/WATCH.

- Source application: industrial and residential water filtration.
- Function: use accumulated pressure differential across a screen/filter as the trigger for a cleaning/backflush cycle; in some hydraulic systems the line pressure itself powers the cleaning mechanism.
- Physical principle: differential-pressure threshold + reversed/redirected flow + hydraulic actuation.
- Demonstrated capability: commercial automatic backflush filters use pressure differential or scheduled cycles to clean filter surfaces; GEFA describes hydraulic backflush driven by line pressure and a rotating internal cleaning mechanism without external power; Puretec uses an automatic brushing/discharge architecture.
- Transfer boundary: shower-scale packaging, available differential pressure, cleanable screen area, potable-water materials, backflow protection, noise, pressure loss, and where the dirty flush water can discharge must be verified.
- Potential fitting insertion: inlet strainer / pre-filter module / filter cartridge housing upstream of the spray face.
- Evidence: GEFA TYPE M1XX automatic backflush filter; Puretec IAB automatic self-cleaning filter.
- External evidence: https://www.im-tek.com/gefa-type-m1xx-automatic-backflush-filter-amp.html ; https://www.puretec.com.au/IAB25W
- Existing Knowledge: current Tech Radar includes pressure-compensating/self-flushing emitters (TR-001), compact hydrocyclone separation (TR-011), and point-of-use filtration (TR-010), but no direct record establishes a compact pressure-triggered backflush screen for a showerhead inlet.

## RS-12 — Idea Convergence

### C-01 — Self-Centering Hose Parking Dock
**Lane:** Market Pull + Tech Push / Recombination
**Disposition:** KEEP

- Problem / opportunity: keep a handheld-shower hose from protruding into the user's body path or returning to an unwanted side position while preserving free handshower movement.
- Existing solution / source: swivel hose connectors and conventional docks; GROHE Movario uses a rotating connector to reduce hose twisting; TR-017 provides an adjacent self-centring coupling principle.
- DELTA: combine low-torque rotational decoupling with a passive hose-routing/parking geometry that biases the hose toward a controlled neutral path.
- Proposed product response: dock/connector assembly with a free-rotating hose interface plus a compliant or guided parking channel that captures the hose near the wall without restricting extraction.
- User benefit: less hose interference, fewer accidental bumps, and more predictable handshower handling.
- Mechanism: swivel/torsion decoupling + passive self-centering/guided routing.
- Fitting application: handshower dock / wall connection / hose interface.
- Evidence status: EVIDENCED user signal + commercial swivel precedent; combined architecture PROPOSED.
- Main uncertainty: whether a passive routing element can control hose position across different hose stiffnesses, lengths, installation heights and bathroom geometries without making extraction awkward.
- Suggested downstream prompt: IR-01 → IR-02; if architecture gap remains, RS-03/RS-04.

### C-02 — Pressure-Triggered Self-Backflushing Shower Inlet Screen
**Lane:** Tech Push
**Disposition:** WATCH

- Problem / opportunity: inlet screens and filtration elements can accumulate sediment/mineral debris and increase pressure loss or reduce flow.
- Existing solution / source: replaceable shower filters/screens and industrial/residential automatic backflush filters.
- DELTA / transferable capability: use the shower's own pressure differential to trigger a short hydraulic cleaning event rather than requiring routine manual screen removal.
- Proposed product response: compact screen module with a differential-pressure element that redirects a small amount of flow through the screen in reverse and discharges the loosened debris through a controlled path.
- User benefit: longer stable flow and less manual filter/screen maintenance.
- Mechanism: pressure-differential threshold + hydraulic bypass/backflush.
- Fitting application: handshower inlet / showerhead filter module / upstream serviceable screen.
- Evidence status: commercial backflush mechanism EVIDENCED; shower-scale transfer UNKNOWN.
- Main uncertainty: available pressure differential may be too low after fixture losses; reverse-flow discharge, backflow protection, potable-water compliance, sealing, noise and package size require verification.
- Suggested downstream prompt: IR-01 → RS-03/RS-04/RS-06.
