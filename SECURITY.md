# Security

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in public issues or pull requests.

Use GitHub's private security reporting mechanisms when they are available for this repository. Include the affected path, a concise description, reproduction details when safe to share, and the potential impact.

## Security baseline

This public repository relies on GitHub-managed secret scanning for public repositories and uses Dependabot version updates for GitHub Actions. Repository workflows should keep the minimum permissions required for their jobs.

Security controls are protection layers only; they do not change the Second-Brain knowledge, Claw, or PR lifecycle.
